# 架构与时序图

本目录 `diagrams/` 提供 8 张逐工具方案图（SVG矢量原图），`diagrams/index.html` 可离线打开查看全部图。图中文字和连线由结构化图数据绘制，不是AI生成的示意文字。下列Mermaid图提供可编辑的全局架构、调度和生命周期关系。

## 功能架构

```mermaid
flowchart TB
  subgraph RT[VisionRT]
    Catalog[JSON扫描与工具目录]
    Editor[工程与节点配置]
    Resolve[节点契约物化]
    Runtime[调度与门控]
    Readers[读回与点选协调]
    UI[画布与参数面板]
    Catalog --> Resolve
    Editor --> Resolve
    Resolve --> Runtime
    Runtime --> Readers --> UI
    UI --> Editor
  end
  subgraph SDK[VisionRTContracts ABI 4]
    Contract[IToolInstance与工厂接口]
    Value[可写DataRef与Owner]
  end
  subgraph VT[VisionTools]
    Preprocess[文件取图与图像处理]
    Logic[Python表达式与条件]
    Metrology[圆与行间距测量]
    Assist[智能点选辅助实例]
    Kernel[共享OpenCV测量内核]
    Metrology --> Kernel
    Assist --> Kernel
  end
  Runtime --> Contract
  Readers --> Contract
  Contract --> Preprocess
  Contract --> Logic
  Contract --> Metrology
  Contract --> Assist
  Value --- Runtime
  Value --- Contract
```

JSON由RT读取；注册工厂与算法由Tools实现。辅助工具不创建新的接口体系。图中的所有权连线表示保活关系，不表示数据只读或自动复制。

## 发现与实例化

```mermaid
sequenceDiagram
  participant RT as VisionRT目录
  participant JSON as 声明JSON
  participant Registry as 注册表
  participant Adapter as Python适配器
  participant Tool as 工具实例
  RT->>JSON: 扫描内建与自定义来源
  JSON-->>RT: kind / tool_id / entry / ports
  RT->>RT: 校验并物化节点契约
  alt C++
    RT->>Registry: 按tool_id获取手写工厂
    Registry->>Tool: 创建独立实例
  else Python
    RT->>Adapter: 按来源根解析package/file/symbol
    Adapter->>Tool: 加载类并创建实例
  end
  RT->>Tool: initialize(普通Values)
  RT->>Tool: execute(输入Values)
  Tool-->>RT: ToolStatus与输出Values
```

## Once 与 Loop

```mermaid
flowchart TB
  Start[接受运行请求] --> Drain[归还点选与现有读者租约]
  Drain --> Freeze[冻结配置与节点契约]
  Freeze --> Round[提交本轮所有选中flow]
  Round --> Gate[逐节点检查guard和本轮输入]
  Gate -->|可执行| Execute[初始化或复用实例并执行]
  Gate -->|不可执行| Skip[发布Skipped或Blocked终态]
  Execute --> Done[全部flow完成]
  Skip --> Done
  Done --> Clock[记录flow与全流程墙钟]
  Clock --> Mode{Loop且未Stop}
  Mode -->|是| Light[轻量状态发布]
  Light --> Round
  Mode -->|否| Read[最终图像ROI文本读回]
  Read --> Ack[所有读者ACK]
  Ack --> Complete[发布completion并冻结elapsed]
```

## 跨语言图像保活

```mermaid
flowchart TB
  CPP[DataRef Image中的cv Mat] --> Cap[Python base capsule]
  Cap --> Storage[共享ImageStorage]
  Storage --> Owner[原Mat或外部Owner]
  Cap --> Array[NumPy ndarray视图]
  Array --> Slice[Python裁剪或返回新数组]
  Slice --> Validate[验证dtype步长范围与真实可写存储]
  Validate --> U[Mat UMatData持有Storage]
  U --> Child[C++ Mat浅拷贝与ROI]
  Child --> Last[最后一个Mat头释放]
  Last --> Release[归还Python引用或原Owner]
```

这是两个传递方向的概念图，不表示应构建强引用环。对回环数组复用已有Storage，并依据返回视图重建Mat头。

## 智能点选与关闭顺序

```mermaid
sequenceDiagram
  participant UI as ImageViewport
  participant PC as PreviewCoordinator
  participant Helper as 独立辅助工具
  participant Runtime as Runtime协调器
  participant Python as Python存储
  UI->>PC: 悬停与稳定publication
  PC->>PC: 持Owner与内部读者租约
  PC->>Helper: 有界候选计算
  UI->>PC: Close或Reset
  PC->>PC: 作废上下文并清空pending
  Helper-->>PC: 结束并归还结果
  PC->>PC: 丢弃陈旧结果并释放内部Owner
  PC->>Runtime: 推进异步reset与release
  Runtime-->>PC: 正式实例和结果已释放
  PC->>Python: prepareShutdown
  alt 存在外部Owner
    Python-->>PC: AwaitOwners
    Python-->>PC: 外部最后引用归还
  end
  PC-->>UI: closeReady恰好一次
```
