# VisionRT / VisionTools 七工具与智能点选：完整方案、Specs、Tickets

当前代码基线复核日期：2026-10-25。原设计的目标功能保持有效；当前落实情况以[本轮验收报告](../00_验收报告.md)为准。状态：待实施的设计交付；本包不表示功能已实现、测试已通过或安装包已发布。

本方案以 `refactor/abi4-writable-data` 分支的 VisionRT `f6f57b03adea1c732492e635a7c09bdc19cbe26c`、VisionTools `b24307b7bcb687a3b8f9fe2269aff528b054de6f` 为代码基线，结合本次提供的 8 份参考文档及此前可写数据、JSON、循环读回、关闭状态机和连接约束方案。基线之后的提交不在本次核对范围内。

**全部功能使用 OpenCV、标准 C++、现有 Qt / pybind11 / Taskflow，以及开源 Python 表达式组件完成，不使用 HALCON。** 七项业务工具是文件取图、旋转、亮度、表达式、条件分支、测量圆、测量行间距；智能点选是配套交互能力。另外包含分支合流宿主工具和两个隐藏的点选辅助工具。
