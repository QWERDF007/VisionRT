# 端口契约

此表是设计接口。所有声明均有隐式系统状态输出，不在业务 outputs 重复声明。`—` 表示没有默认值，不表示 Missing 与空值相同。N 为图像数，M 为名义 ROI 数，K 为该 ROI 或图像的有效结果数。

固定工具的 init_params 为空。表达式和分支的变量/程序表由 RT 派生；select 示例里的 Int 是基础占位类型，物化后两个分支输入与输出全部替换成节点 select_type。JSON 示例不能由当前 schema 2 解析器直接加载。

## 补充约束

- circle：valid/reasons 为 [N][M]；有效结果 centers 为 [N][K][2]，其余数值 [N][K]，source_roi_indices 为 [N][K]；used_edges 为 [N][K][kind5记录]。
- row：width_min/max 的比较量纲为像素（与 width_px 对齐）；物理宽度输出不改变筛选量纲。width/gap/pitch 的 K/K-1 规则见 S-ROWS-01。
- center=[] 表示各图默认中心，非空必须恰好两个有限值。border_value 长度为1或通道数；不能让不同通道数量的图复用一个不匹配的四元数组。
- circle 要求 radius_min≤radius_max、min_points≤num_calipers、搜索半宽小于变换后的名义半径。计数和窗口乘积必须有溢出检查及采样预算，拒绝极大组合而不是先分配。
- row 要求 width_min≤width_max，ROI宽高足以支持滤波；0对的 valid_roi=false，原因“未找到完整边缘对”，不返回失败工具状态。
- helper 无候选时 candidate_valid=false、ROI=[]，推荐数字输出为合法默认值但禁止消费；quality是简短文字，不是伪造置信概率。Learn失败不能据这些默认值覆盖工程。
- helper search_extent 是当前图像像素范围预算；金字塔只改变采样成本，不允许越过明确搜索范围。缺省256不能承诺检测任意大圆。
- 所有正式工具需要的无默认必需输入由用户绑定或手动填写；灰色“未配置”不自动转换为0或空字符串。
