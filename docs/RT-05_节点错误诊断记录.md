# RT-05 节点错误诊断与四态区分记录

## 1. 历史截图橙色节点复现与根因分析

在历史会话验收（如 2026-10-17 14:56:49 与 14:57:31 截图）中，画布上的 YOLO 节点和裁剪节点呈现橙色边框/高亮，当时曾引起“是否推理成功”或“为何显示橙色”的疑问。经系统代码级审查与现场复现，定位根因如下：

### 1.1 历史 UI 渲染逻辑缺陷
- **旧代码行为**：在旧版 `NodeDelegate.qml` 中，`isError` 被定义为 `root.nodeState === "red" || root.node.missing === true`。而在绘制边框时，错误状态直接使用了 `Theme.quiColorWarning`（橙色 `#ea580c`）。同时，选中状态覆盖了错误态，未运行/运行中/成功/错误四态没有做明确的背景与状态圆点分离。
- **误导后果**：任何失败（无论是定义缺失、实现加载失败还是输入契约失败）均显示为橙色；且由于右侧视图在下游失败时仍保留了上游读图的成功结果，容易让用户误以为 YOLO 节点“执行成功但显示异常”。

### 1.2 YOLO 节点候选原因分析 (状态码 -3)
- **输入与参数**：历史工程中 YOLO 节点的 `model_path` 指向本地尚未生成的 `.engine` 或缺失的 ONNX 权重文件，或在无独立 NVIDIA GPU 的清洁机器上启动。
- **执行路径**：`YoloTool::initialize` 调用 `irt::model::CreateModel("yolov8n")` 或 `LoadModel`，由于权重不存在或 CUDA 环境不满足，返回错误状态码 `-3`（`ToolStatus{-3, "InferRT CreateModel(yolov8n) returned null"}` 或 `cudaGetErrorString` 报错）。
- **证据边界**：历史截图未附带原始终端运行日志；上述分析为根据拓扑参数和当前加载链代码复现的候选原因。在缺少真实 GPU 硬件或模型权重的环境下，真实模型推理正确性标明为未验证（unverified/unsupported），不以非零初始化报错替代真实模型计算正确性。

### 1.3 裁剪节点候选原因分析 (状态码 -2)
- **输入与连接**：历史截图拓扑中，读图节点直接连接到裁剪节点，而没有经过 ROI 投影或生成 ROI 批次。
- **执行路径**：`visionrt.image.crop` 声明必须包含 `images` (ImageBatch) 与 `rois` (RoiBatch) 两个输入端口。由于未连接 ROI，`NodeRuntime` 检查到 `rois` 值为 `Missing`，抛出契约异常：`ContractError("Missing input: rois")`，返回状态码 `-2`。
- **证据边界**：历史截图无现场运行日志留存，本项为根据拓扑缺输入复现的候选原因。已在临时隔离工程 `examples/pipeline_error_diagnostic.vrt` 中固化为确定性契约测试。

## 2. 诊断体系与四态视觉落地改进 (RT-01, RT-05, RT-12)

经过本次重构，VisionRT 实现了严格、透明且与选中态解耦的节点诊断与视觉呈现：

1. **四态独立背景与指示器**：
   - **未运行 (Gray)**：浅灰底色（`#f8f9fa`），灰色圆点，未执行时干净整洁。
   - **运行中 (Blue)**：浅蓝底色（`#dbeafe`），蓝色圆点（`#1d4ed8`），明确指示调度器在途。
   - **成功 (Green)**：浅绿底色（`#dcfce7`），绿色圆点（`#15803d`），仅在 `status.code == 0` 且所有业务输出非 Missing 时呈现。
   - **错误 (Red)**：浅红底色（`#fee2e2`），红色圆点（`#b91c1c`），红边框。
2. **精细化错误徽章**：
   - **缺定义**（DefinitionMissing）：顶部徽章黄色 `缺定义`，提示未找到算子元数据 YAML。
   - **缺实现**（ImplementationUnavailable）：顶部徽章橙色 `缺实现`，提示动态库未加载或工厂为空。
   - **执行错误**（Execution Error）：顶部徽章红色 `执行错误`，代表运行时契约异常或算法业务返回非零。
3. **Tooltip 与参数表全量关联**：
   - 悬浮在节点上时，Tooltip 明确打印：`❌ 错误信息: [状态码] 详细错误原因`。
   - 选中节点后，右侧“输出参数”表首行清晰展示 `__status_code` 与 `__status_message`。
4. **隔离性保证**：
   - 上游节点业务失败时，下游节点不读取旧快照，安全阻断；其余无关分支流程继续执行。

## 3. 可复现工程说明

本诊断由 `examples/pipeline_error_diagnostic.vrt` 进行确定性复现：
- 节点 1 (`visionrt.image.read`): 正常读图（绿色成功态）。
- 节点 2 (`visionrt.image.crop`): 故意不连接 `rois` 端口，复现缺失必需输入时的契约错误（返回错误码 -2，UI 标记“执行错误”并显示状态码与缺失端口）。
- 节点 3 (`visionrt.dl.yolo`): 指定不存在的模型权重，复现模型加载失败（返回错误码 -3，UI 标记“执行错误”并显示加载错误详情）。
- 节点 4 (`unavailable.custom.plugin`): 算子定义不存在，复现定义缺失（UI 顶部徽章显示“缺定义”，不可执行）。
