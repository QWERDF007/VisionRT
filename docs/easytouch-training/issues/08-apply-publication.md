# 08：点击应用，成功一次发布、失败可重试

**What to build:** 用只产普通参数的真实工具打通应用：成功前旧结果可运行，成功后正式参数与可重开的训练来源一起生效；同一发布器也接收带模型的返回。

**Blocked by:** [07 把声明指定的原始帧加入内存草稿](07-memory-training.md)

**Status:** ready-for-agent

**归属：** VisionRT、VisionTools 测试消费者 | **规格验收：** [A3、A4](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 在现有应用入口捕获完整草稿；后台使用普通工具生命周期。失败、无效返回、过期或重复点击不得发布；保留草稿供直接重试。测试夹具走真实工厂，不加产品按钮或生产测试工具。
- [ ] 一次提交所有参数、资产相对引用与执行修订。仅参数训练保存成功来源，不建空模型；用带一个小模型的集成夹具打通同一 manifest/不可变 revision 协议，为两种业务训练器复用。
- [ ] 训练器先在内存用同一私有解码器回读，宿主验证声明输出后才允许暂存。分别注入算法错、错误字节/类型、写盘失败和节点提交拒绝；前两者零训练写入，后两者只清理本次未发布内容，旧模型可运行。
- [ ] 在已保存普通工程重开刚保存的正式来源和结果；故意缺失文件明确诊断。无已发布结果时只阻止相关训练节点。验证实例缓存与 initialize 使用同一物化参数，无需再调用 reloadNode 增加第二次修订。
