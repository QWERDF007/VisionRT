# 11：在训练图点选和追加参考边

**What to build:** 用户悬停看候选，单击替换、Ctrl 点击追加第二条边；手绘与点选最终调用同一个真实训练器。

**Blocked by:** [05 圆测量一次点击提交完整配置](05-circle-pick.md)、[10 用参考原图训练两条实测边](10-edge-model.md)

**Status:** ready-for-agent

**归属：** VisionTools、VisionRT | **规格验收：** [A2、A3、A5](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 点选原图按恒等对齐读取；在已有完整 ROI 组上估计替换/追加后的对比度、宽度及极性，统一法向；宽度确定后以相同尺度复测对比度，最低完整度保持用户值。
- [ ] 用已知阶跃、模糊、噪声、反极性校准比较，可靠响应异号得到 any；搜索半径与搜索带短边各自生效。88 px 仅用于线缆右侧试验，另验未吸附邻边。
- [ ] 第一次点选即能编辑；草稿的几何与参数整组写入内存。完成第二条、拖框或失焦仍不发布。切图、换页或更换记录后迟到的悬停和学习结果不提交。
- [ ] 真实鼠标完成两次点击后再按应用，以 A5 复核实测线和姿态；禁用点选仍可沿用手绘训练。
