# 07：把声明指定的原始帧加入内存草稿

**What to build:** 用户在现有训练页加入和编辑原始帧，离开再返回仍能继续；点第一条边或首次加入不写磁盘、不改变可运行工程。

**Blocked by:** [02 作者与宿主报告相同的声明错误](02-authoring-catalog.md)、[03 原生插件可消费同一张原图的多条记录](03-native-training-set.md)

**Status:** ready-for-agent

**归属：** VisionRT、Contracts | **规格验收：** [A1、A2、A3](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 从声明指定的端口发布值、批次索引和身份读取一帧，深拷贝像素并保留颜色顺序；用显示转换会改变的图验证不会从 QImage 取样。可共享同图的多条记录使用稳定身份。
- [ ] 列表、缩略图、字段控件及画布从内存和声明派生。第一条边和不完整记录可编辑；应用资格另算。训练页不被运行结果覆盖，普通节点不显示训练页。
- [ ] 换节点或切页可继续同工程草稿；删节点、关闭/替换工程后释放。覆盖切换后迟到的预览；对比 init、dirty、执行修订和值，验证均未变。
- [ ] 用训练写入观察点和系统级文件创建事件覆盖工程、安装、宿主管理的工作区及临时区。首次加入、拖框、改字段、保存、另存均未创建草稿文件；工程 JSON 自身的正常保存另计。
- [ ] 用真实训练集端口把目录校验与票 03 的实际类型连起来，负例拒绝不匹配的调用；此票可用工作台夹具演示，无需真实识色或直边训练器。
