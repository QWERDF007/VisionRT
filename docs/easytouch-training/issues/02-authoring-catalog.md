# 02：作者与宿主报告相同的声明错误

**What to build:** 作者可把处理或训练作用域绑定到隐藏工具，不启动 GUI 即知道声明能否装载；安装相同声明时得到相同诊断。

**Blocked by:** [01 普通工具通过同一 SDK 声明往返](01-sdk-declaration.md)

**Status:** ready-for-agent

**归属：** Contracts、VisionTools、VisionRT | **规格验收：** [A1、A8](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 同一工具身份装载无能力、处理点选、手绘训练、训练点选四种声明；两端调用同一套 UTF-8 读写和整目录校验，普通工具仍可装载。
- [ ] 交叉验证调用、初始化与执行输入、预览与有效标志、完整 writes、可选消息、产物及参考线。错误阶段、跨作用域、冲突写入、缺助手、递归引用和类型不符须定位工具及字段路径；给出类型上下文。
- [ ] 安装 SDK 的无 GUI 消费者和宿主校验器对同一负例得到同一结构化错误；包文件、DLL 和真实注册的校验仍由各自现有边界负责。声明合法与当前工厂可用分别判定。
- [ ] 用普通标量、ROI 和参数型训练调用验证映射；新训练集值在票 03 可用后，由首次训练联调验证，不在 SDK 临时接受未知数值枚举。
