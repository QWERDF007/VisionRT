# 12：另存后独立重开已发布模型

**What to build:** 把已训练工程另存到其他位置，移开原文件仍可运行和继续训练；安装示例、未命名工程和未应用草稿不污染目标目录。

**Blocked by:** [08 点击应用，成功一次发布、失败可重试](08-apply-publication.md)

**Status:** ready-for-agent

**归属：** VisionRT | **规格验收：** [A3、A4](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 已命名工程发布到工程旁的资产树；未命名及安装示例只在首次训练成功后使用工作区。以真实文件和发布器夹具覆盖格式 8 的可选相对引用、来源图片和模型；普通工具路径解释不变。
- [ ] 先备资产后原子提交工程 JSON。保存已有模型和新的未应用编辑，只复制旧正式 revision；首次未应用保存不含训练引用。仅参数资产同样能重开，保存本身不训练。
- [ ] 源工程移走后重启，验证原始像素、位深、通道顺序、训练参数及运行模型。多记录同图只保存一份原图；选择不同目标根后缓存比较与 initialize 都解析新位置。
- [ ] 注入资产复制或工程提交失败，对比原工程、目标原有内容与节点状态；绝不删除早先引用的版本或改写安装资源。损坏正式来源/模型给出诊断，不使用其他目录兜底。
