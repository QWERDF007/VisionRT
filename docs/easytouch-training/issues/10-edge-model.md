# 10：用参考原图训练两条实测边

**What to build:** 用户手绘两个有向搜索矩形即可训练参考姿态，在训练页看到像素拟合的实测线；无需等待点选助手。

**Blocked by:** [08 点击应用，成功一次发布、失败可重试](08-apply-publication.md)

**Status:** ready-for-agent

**归属：** VisionTools、VisionRT | **规格验收：** [A4、A5](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] TrainStraightBorders 复用 EdgeProfile 与 StraightEdgeLocator，按两条搜索区、同一通道和参数拟合；输出版本化模型及训练原图坐标的可选 ROI 叠加。宿主既不推导端点也不解码私有模型画线。
- [ ] 模型持有搜索区、实测端点与训练参数，运行只加载并求参考到当前的刚体变换。缺边、平行或退化须指出具体区域，非直角有效；错误模型或错边不能作为成功示例。
- [ ] 直接手绘并应用，以参考图和沿法线双向移动搜索框验证规格 A5 的角度、平移及边位置。记录矩阵和叠加图；换训练输入时不显示属于旧输入的参考线。
