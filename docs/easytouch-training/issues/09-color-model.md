# 09：在工作台手绘取样并发布颜色模型

**What to build:** 用户按名称圈出样本后应用，识色节点直接加载发布模型；运行和修改检测阈值均不再训练。

**Blocked by:** [08 点击应用，成功一次发布、失败可重试](08-apply-publication.md)

**Status:** ready-for-agent

**归属：** VisionTools、VisionRT | **规格验收：** [A4、A6](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 用真实 TrainColorModel 接收训练集和字段 ID；支持 8 位 BGR，矩形、圆、多边形复用掩膜。同名标签跨图聚合；重叠区域保持既有逐区域累计口径。不支持的像素类型返回工具诊断。
- [ ] 模型含版本、色彩预处理约定、类别顺序、均值、逆协方差、对数行列式及像素计数；训练端回读与 RecognizeColor 初始化用同一解码器。损坏或不兼容模型不触发重训。
- [ ] 对比固定旧样本、内存模型、加载模型和重开工程的逐工位标签及 float32 分数/比例。覆盖纯色、背景、混色、空掩膜、并列与 unknown，不改变票数、分数和比例定义。
- [ ] 工作台手绘多条记录后训练、运行五个圆工位，仅修改检测阈值验证训练调用数不变；失败后恢复旧正式结果。
