# 05：圆测量一次点击提交完整配置

**What to build:** 打开圆测量的当前帧，悬停预览候选，点击提交完整圆组、半搜索宽度和极性；既有上游连接受到保护。

**Blocked by:** [02 作者与宿主报告相同的声明错误](02-authoring-catalog.md)

**Status:** ready-for-agent

**归属：** VisionTools、VisionRT | **规格验收：** [A1、A2](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 在真实工作台和真实圆助手上用单图、批图、共享/逐图 ROI 及非单位对齐重放。按声明解析原图、光标、阶段、已有 ROI 与追加意图，助手返回完整组。
- [ ] 悬停零写入；学习成功且 valid 才一次经 ProjectEditor 提交。初始化或普通输入按其阶段验证，任一目标非法或已绑定上游则整组不变；成功改动只增一次执行修订。
- [ ] 以可替换声明改变映射端口和 ROI 顺序，证明不靠第一个 ROI 或固定编号。开关关闭、无图、工厂不可用、过期结果均不接管错误帧；手绘、平移、缩放可用。
- [ ] 保留既有有界预览通道、点击优先及释放语义。普通工具不占训练栏、不启动助手，也不改全局偏好。
