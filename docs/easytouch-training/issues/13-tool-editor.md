# 13：自定义工具编辑与复制保留能力声明

**What to build:** 工具作者打开、复制和保存带能力的声明，再次发现时可使用同样的交互；端口改型或删除不暗中破坏助手和训练器。

**Blocked by:** [02 作者与宿主报告相同的声明错误](02-authoring-catalog.md)

**Status:** ready-for-agent

**归属：** VisionRT | **规格验收：** [A1、A8](../../VisionRT_EasyTouch与训练实施方案.md#验收规格)

## 验收条件

- [ ] 打开并原样保存双作用域声明；通过 SDK 读回，能力、端口编号和相关资源语义不变。取消复制/编辑不写文件，保存后的复制品可由真实注册表重新发现。
- [ ] 改型、删端口或重命名涉及调用、字段或产物引用时，显示准确影响；无法整体保持合法时拒绝，旧草稿和磁盘声明不变。验证多草稿的目录级引用，而非只检查当前选中项。
- [ ] 复用工具编辑器与 SDK 验证；不引入完整的图形化声明设计器。隐藏助手、训练器不出现在普通工具树。
