## 2. 独立执行

| 检查 | 实际方式 | 输出文件 |

| Python 工具 | python3 -B tests/test_python_tools.py -v；本机 NumPy | evidence/python_tools_test.txt |
| DataRef | g++ C++20，引用实际 DataRef.h，无替代实现 | evidence/dataref_probe.cpp / .txt |
| YOLO padding | g++ C++20，编译实际 src/infer/YoloPostprocess.cpp | evidence/yolo_padding_probe.cpp / .txt |

环境为 Linux，有 g++/Python/NumPy，无 cmake、pkg-config 和 cv2 模块；本次没有搭建 Qt/OpenCV/CUDA 构建链。没有用模拟 Mat 或假 validator 代替生产契约，也没有把不能执行的 Windows 测试标为通过。

YOLO 探针可在 VisionTools 检出的固定提交根目录用以下命令重跑（将 probe 源码复制到可访问目录）：

```bash
g++ -std=c++20 -O2 -Wall -Wextra -pedantic -I src/infer /path/to/yolo_padding_probe.cpp src/infer/YoloPostprocess.cpp -o /tmp/yolo_padding_probe
/tmp/yolo_padding_probe
```

该 probe 退出 0 表示已复现原缺陷，修复后的正式测试必须反转为期待有效框保留。这里只编译纯后处理，不代表完整 GPU 推理已通过。
