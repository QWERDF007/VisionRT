**Specification:** [D-01、D-02、D-05 至 D-13；US-11、US-12、US-17、US-18、US-23、US-24、US-34；T-08、T-09，组合 T-02、T-04 至 T-07、T-10](../spec.md)。

- [x] 从现有混合包更换为另一完整包，重启后新增工具可用，删除工具有明确工程诊断，旧包独有 DLL、脚本和资源不残留。
- [x] 损坏 ZIP、绝对路径或链接逃逸、缺文件、重复工具身份及外置索引不一致明确拒绝；拒绝前有效安装内容和运行结果不变。
- [x] 文件被宿主占用或目标写入失败时返回失败，不强杀进程、不报告假成功；不引入热升级、差分包或断电恢复系统。
- [x] 在没有源码树和开发 PATH 补偿的中文/空格安装路径，实际运行领域 DLL、Python 工具和平台接收节点，并验证固定数值及保存重开。
- [x] 实际移除一个传递依赖会出现加载错误，恢复后可运行；不能仅因顶层 DLL 存在就宣布包可用。
- [x] 按实际交付配置验证依赖、资源及目标环境前提，不按计算后端预设包类型或排除必要文件；缺少硬件、模型或依赖的执行项逐项记录 not_run，不用其他配置的成功代替，不计为通过。
- [x] 三仓采用一致的 SDK 基线和工作区源码，核心独立消费和可选 PythonInterop 均通过；生产中不残留旧格式、旧目录部署和重复转换路径。
- [x] 先补针对更换与失败保护的局部测试，再实现；最终结合真实部署演示和必要整体回归收口，文档只保留规格索引和验证证据。

**验证演示：** 对可运行安装依次尝试坏包与有效新包：坏包被拒绝且原工程仍可运行；退出宿主后安装新包，重启验证完整工具列表及结果，记录缺资源的未运行项。
