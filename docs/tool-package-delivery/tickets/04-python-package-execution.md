# 04: Python 工具随 ZIP 离线安装并按索引执行

**What to build:** Python 算法作者只提交声明、脚本及必要资源，即可随工具 ZIP 离线部署，在宿主列表中出现并运行，不需要虚构 C++ 模块或依靠源码目录导入。

**Blocked by:** [03：领域 DLL 经工具 ZIP 部署到宿主执行](03-zip-deployment.md)。

**Status:** completed — 已完成并通过验收测试。

**Specification:** [D-04 至 D-07；US-13、US-14、US-19、US-20；T-04](../spec.md)。

- [x] Python 工具以 tool_id 引用自己的声明和脚本；混合包与不含领域 DLL 的纯 Python 包均可校验、部署和运行。
- [x] 相对导入及必要相邻资源按声明随包交付，不因工具的计算后端另走打包或加载流程；部署到中文及空格路径仍正确，不注入开发机源码路径。
- [x] 同一 Python 入口的声明变化正确反映到工作台名称、分类、参数和端口；仅展示工具列表不执行算法或初始化模型。
- [x] 索引外的额外 Python 文件不得自动成为工具；缺脚本、入口无效和执行错误有明确诊断。
- [x] 使用当前唯一的 Python 转换实现，不复制转换代码；本片不以可选目标的代码迁移作为交付前提。
- [x] 先补真实脚本、NumPy、相对导入和资源读取的失败用例，再实现完整打包到运行链路。

**验证演示：** 从源码树外部署并运行带相对导入和相邻资源的 Python 图像工具，验证数值；额外放入未索引脚本后，工具列表保持不变。
