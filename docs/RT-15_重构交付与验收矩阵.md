## 2. 宿主单源配置与交接规范 (RT-11, RT-13 / VR-10)

为消除配置分叉与历史包袱，本仓库实施统一单源配置：
1. **依赖与路径单源**：[`cmake/ConfigDefaults.cmake`](../cmake/ConfigDefaults.cmake) 定义 Qt、OpenCV、Python 的默认发现路径与编译选项，修改一处即可作用于 CMake 配置与 [`tools/build.cmd`](../tools/build.cmd)。
2. **构建与打包唯一入口**：[`tools/build.cmd`](../tools/build.cmd) 提供一键编译（`--build`）、全量测试（`--test`）及分发打包（`--package <dir>`）；[`tools/package_app.py`](../tools/package_app.py) 提供 `--test-verify` 自检测试。
3. **视觉主题单一真相源 (SSOT)**：通用控件全面回归 `quickui::quickui` 原生样式；业务四态状态色（灰、蓝、绿、红）与状态徽标在 [`Theme.qml`](../src/ui/qml/Theme.qml) 与 [`NodeDelegate.qml`](../src/ui/qml/NodeDelegate.qml) 统一定义，无外部冗余复述。
4. **文档入口单一真相源**：[`docs/README.md`](README.md) 为系统设计规范与接口索引唯一入口，旧 bridge 文档转为接口合同索引。

## 4. 性能回归实测数据 (RT-07 / RS-07 / VR-09)

测试程序：[`tests/performance_contract.cpp`](../tests/performance_contract.cpp)

### 4.1 200 节点拓扑图执行延迟 (A15)
- **拓扑结构**：200 个串联加法节点构成的 DAG 拓扑，包含 5 轮预热 + 30 轮连续实测。
- **分位数测量结果**：
  - **p50**: `15.36 ms`
  - **p95**: `15.97 ms`
  - **p99**: `16.17 ms`
- **验收结论**：调度执行延迟 p95 远优于目标红线（目标 ≤ 100ms），**实测通过**。

### 4.2 真实 10 张 4K 图像零拷贝扇出与 Python 透传实测 (B05)
- **输入规模**：10 张 4K 图像批次（3840 × 2160 × 3 通道，单批次原始像素 ~248.8 MB）。
- **C++ 扇出分支**：100 个消费者分支并行读取上游 `ImageBatch`（产生 1000 个 4K 图像只读视图）。
- **内存与指针验证**：
  - 各分支全部 10 张图像的 `readOnlyMat().data` 与原始像素首地址完全一致（指针恒等）。
  - 进程 Working Set 增量仅为 4 KB（引用元数据开销）。
  - 若发生拷贝则需占用 ~24.8 GB 内存，实测证实**按边像素拷贝数为 0**，**实测通过**。
- **Python 透传与单次叶子拷贝**：
  - Python 只读输入视图直接包裹底层像素指针，避免内存拷贝；
  - 算子返回新叶子输出时完成单次内存规整，生命周期结束后自动析构回收，**实测通过**。

### 4.3 循环压力与内存稳定性监测
- **循环轮次**：连续执行 100 轮 DAG 计算，实时采集 Windows Process Working Set (RSS)。
- **RSS 内存曲线**：
  - 初始值：`42,780 KB`
  - 第 20 轮（稳定基线）：`43,684 KB`
  - 第 50 轮：`43,684 KB`
  - 第 75 轮：`43,684 KB`
  - 第 100 轮：`43,684 KB`
  - 重置后（AfterReset）：`43,684 KB`
  - 进入稳态后内存增量为 0 KB，无单调泄漏趋势；
  - 原始曲线数据自动持久化至 `build/evidence/memory_curve.csv`。
- **显存与硬件边界**：在无独立硬件 GPU 设备活动时，显存监控明确报告为 `unsupported`，不以返回伪造 0 谎报通过。

### 4.4 GUI 事件到呈现延迟
- **测量方式**：真实 `QQuickWindow` 视口，100 次高频鼠标事件分发与 Polish/呈现闭环实测。
- **延迟分位数**：
  - **p50**: `0.0010 ms`
  - **p95**: `0.0035 ms`
- **验收结论**：远优于 100ms 验收红线，**实测通过**。

### 4.5 工具库树模型检索响应
- **数据规模**：500 个已注册工具定义、多级分类树。
- **100 次模糊搜索与过滤响应耗时**：
  - **p50**: `0.0319 ms`
  - **p95**: `0.0505 ms`
- **验收结论**：远优于 100ms 验收红线，**实测通过**。

## 6. 最终签收与证据边界声明 (RT-15 / VR-10)

依据真实执行结果对各条目进行状态划分：

1. **宿主实测闭环项（已验证通过）**：
   - VR-01: SDK 独立构建、导出 `VisionRT::ToolSDK`、统一元数据校验；
   - VR-02: 通用 C++ 插件基于 `QLibrary` 常驻生命周期与工厂注册；
   - VR-03: `AppController` 实际接通工具包目录扫描与多格式合并；
   - VR-04: 宿主彻底移除 InferRT/CUDA 生产链接依赖与旧 Infer 入口；
   - VR-05: 发布包校验与用户 `custom/` 目录防覆盖合并保护；
   - VR-06: 抽屉折叠可见按钮优先焦点流转与 960×540/高 DPI 布局契约；
   - VR-07: 执行阶段作用域计时、异常耗时保留与总耗时冻结；
   - VR-08: 示例工程临时副本隔离、重开数值完全一致、损坏输入拦截；
   - VR-09: 200 节点微基准、10x4K 图像零拷贝扇出、稳态内存曲线与 GUI 事件呈现延迟；
   - VR-10: 规范入口统一为 `docs/README.md`，修复失效链接，消除冗余冲突设计。

2. **硬件环境与边界声明（未验证/未支持）**：
   - **GPU 深度学习模型推理**：在当前无 NVIDIA GPU 硬件与缺少 TensorRT 引擎权重文件的测试机器上，真实模型推理正确性标明为**未验证（unsupported/unverified）**，不以初始化失败非零状态替代真实模型正确性。

3. **跨仓库协同边界**：
   - VisionRT 宿主端的接口、加载链路、打包校验与性能指标已全部独立闭环；
   - 外部 `VisionTools` 仓库算子实现的完备性与生产包交付，待 VisionTools 独立整改后进行联合复验。
