## 4. 性能回归实测数据 (RT-07 / RS-07)

测试程序：[tests/performance_contract.cpp](file:///F:/Projects/VisionRT/tests/performance_contract.cpp)

### 4.1 200 节点拓扑图执行延迟 (A15)
- **拓扑结构**：200 个串联加法节点构成的 DAG 拓扑，包含 5 轮预热 + 30 轮连续高精度纳秒计时实测。
- **分位数测量结果**：
  - **p50**: `15.37 ms`
  - **p95**: `15.89 ms`
  - **p99**: `16.06 ms`
- **验收结论**：普通业务浏览与中大型图调度 p95 远优于目标（目标 ≤ 100ms），**通过**。

### 4.2 4K 图像零拷贝扇出实测 (B05)
- **输入规模**：3840 × 2160 × 3 通道 8-bit 图像（单图像素体积 24.88 MB）。
- **扇出分支**：4096 个消费者分支并行读取上游 `ImageBatch`。
- **内存与指针验证**：
  - 各分支 `readOnlyMat().data` 与原始像素首地址完全一致（指针恒等）。
  - 进程 Working Set 仅产生 156 KB 增量（仅为引用元数据）。
  - 若发生拷贝则需占用 100 GB 显存/内存，实测证实**按边像素拷贝数为 0**，**通过**。

### 4.3 循环压力与内存稳定性监测
- **循环轮次**：连续执行 50 轮 DAG 计算，实时采集 Windows Process Working Set (RSS)。
- **RSS 内存曲线**：
  - 初始值：`23,496 KB`
  - 第 10 轮：`23,512 KB`
  - 第 20 轮：`23,516 KB`
  - 第 30 轮：`23,516 KB`
  - 第 40 轮：`23,516 KB`
  - 第 50 轮：`23,516 KB`
  - 50 轮累计增量仅 `20 KB`（完全为单次缓存稳定态），无任何单调爬升。
- **停机与重置**：调用 `requestStop()` 与 `requestReset()` 均在 <1ms 内安全排空并释放，无互等死锁。

### 4.4 工具库树模型检索响应
- **数据规模**：500 个已注册工具定义、多级分类树。
- **100 次模糊搜索与过滤响应耗时**：
  - **p50**: `0.032 ms`
  - **p95**: `0.051 ms`
- **验收结论**：远优于 100ms 验收红线，**通过**。
