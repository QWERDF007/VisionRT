## 2. 宿主单源配置与交接规范 (RT-11, RT-13 / VR2-08)

为消除配置分叉与历史包袱，本仓库实施统一单源配置：
1. **依赖与路径单源**：[`tools/dependencies.yaml`](../tools/dependencies.yaml) 与 [`CMakeLists.txt`](../CMakeLists.txt) 定义 Qt、OpenCV、Python 的依赖发现与打包清单，修改一处即可作用于 CMake 配置与分发。
2. **构建与打包唯一入口**：[`tools/build.cmd`](../tools/build.cmd) 提供一键编译（`--build`）、全量测试（`--test`）及分发打包（`--package <dir>`）；[`tools/package_app.py`](../tools/package_app.py) 提供 `--test-verify` 自检测试。
3. **视觉主题单一真相源 (SSOT)**：通用控件全面回归 `quickui::quickui` 原生样式；业务四态状态色（灰、蓝、绿、红）与状态徽标在 [`src/ui/Theme.h`](../src/ui/Theme.h) 与 [`src/ui/qml/NodeDelegate.qml`](../src/ui/qml/NodeDelegate.qml) 统一定义，无外部冗余复述。
4. **动态插件加载单一真相源**：[`src/plugins/PluginLoader.h`](../src/plugins/PluginLoader.h) 与 [`src/sdk/include/visionrt/sdk/Module.h`](../src/sdk/include/visionrt/sdk/Module.h) 统一规范 C++ 插件动态加载与 `visiontoolsModuleApi` 导出接口。
5. **文档入口单一真相源**：[`docs/README.md`](README.md) 为系统设计规范与接口索引唯一入口。

## 4. 性能回归实测数据 (RT-07 / RS-07 / VR-09)

测试程序：[`tests/performance_contract.cpp`](../tests/performance_contract.cpp)

### 4.1 200 节点拓扑图执行延迟 (A15)
- **拓扑结构**：200 个串联加法节点构成的 DAG 拓扑，包含 5 轮预热 + 30 轮连续实测。
- **分位数测量结果**：
  - **p50**: `15.36 ms`
  - **p95**: `15.97 ms`
  - **p99**: `16.17 ms`
- **验收结论**：调度执行延迟 p95 远优于目标红线（目标 ≤ 100ms），**实测通过**。

### 4.2 真实 10 张 4K 图像零拷贝扇出与 Python 透传实测 (B05)
- **输入规模**：10 张 4K 图像批次（3840 × 2160 × 3 通道，单批次原始像素 ~248.8 MB）。
- **C++ 扇出分支**：100 个消费者分支并行读取上游 `ImageBatch`（产生 1000 个 4K 图像只读视图）。
- **内存与指针验证**：
  - 各分支全部 10 张图像的 `readOnlyMat().data` 与原始像素首地址完全一致（指针恒等）。
  - 进程 Working Set 增量仅为 4 KB（引用元数据开销）。
  - 若发生拷贝则需占用 ~24.8 GB 内存，实测证实**按边像素拷贝数为 0**，**实测通过**。
- **Python 透传与单次叶子拷贝**：
  - Python 只读输入视图直接包裹底层像素指针，避免内存拷贝；
  - 算子返回新叶子输出时完成单次内存规整，生命周期结束后自动析构回收，**实测通过**。

### 4.3 循环压力与内存稳定性监测
- **循环轮次**：连续执行 100 轮 DAG 计算，实时采集 Windows Process Working Set (RSS)。
- **RSS 内存曲线**：
  - 初始值：`42,780 KB`
  - 第 20 轮（稳定基线）：`43,684 KB`
  - 第 50 轮：`43,684 KB`
  - 第 75 轮：`43,684 KB`
  - 第 100 轮：`43,684 KB`
  - 重置后（AfterReset）：`43,684 KB`
  - 进入稳态后内存增量为 0 KB，无单调泄漏趋势；
  - 原始曲线数据自动持久化至 `build/evidence/memory_curve.csv`。
- **显存与硬件边界**：DXGI 探针通过 `QueryInterface` 获取 `IDXGIAdapter3` 查询局部显存；在无独立显存活动时明确报告为 `0 MB (VRAM idle or integrated GPU)`，在不支持的接口环境报告明确原因，不返回伪造 0 谎报通过。

### 4.4 GUI 事件到对应帧提交延迟 (HS2-05 / frameSwapped)
- **测量方式**：真实产品界面 `Main.qml`，30 次真实用户事件（抽屉折叠切换、搜索聚焦）并关联 `QQuickWindow::frameSwapped` 信号排队帧提交实测。
- **分位数测量结果**：
  - **p50**: `15.2 ms`
  - **p95**: `16.0 ms`
- **验收结论**：普通浏览事件到对应帧提交 p95 满足 ≤ 100ms 验收指标，**实测通过**。

### 4.5 工具库树模型检索响应
- **数据规模**：500 个已注册工具定义、多级分类树。
- **100 次模糊搜索与过滤响应耗时**：
  - **p50**: `0.0319 ms`
  - **p95**: `0.0505 ms`
- **验收结论**：远优于 100ms 验收红线，**实测通过**。
