## 必须补充的场景

1. Python新建图像→普通单次完成→直接关窗：不先Reset，无外部引用，窗口正常关闭。
2. 外部保存Mat ROI→关窗进入等待→后续GUI事件释放：仅一次closeReady，GUI不冻结。
3. release等待受控事件→GUI继续响应→事件释放后关闭完成。
4. Once/Node收到Stop、读者未ACK：coordinator有处理机会仍不完成；旧谓词版本应被测试捕获。
5. 输入/输出验证失败：tooltip仍显示已测阶段时间，未进入阶段显示—。
6. 排空中的格式化异常、多个Text/Save请求及同步重入：无意外派发/ACK，队列项明确完成或取消。
7. 实际E盘应用：单次、Loop无重渲染、停止最终图像/ROI、保存重开和直接关窗；解释器路径属于实际部署。
