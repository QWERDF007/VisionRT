# Python图像统计

- 前置条件：在 设置 → Python 环境 选择一个可用的外部解释器（需要 NumPy）。未配置时运行会在节点上报出真实原因，随包的其他 CPU 示例不受影响。
- 使用：文件 → 打开示例… → 本目录的 `Python图像统计.vrt.json`。
- 流程：图像读取 → 投影ROI → 裁剪 → 灰度二值化；同一读图结果另接 计算图像均值（Python）。
- 运行：点击“单次”，查看两条分支各自的图像与数值。
- 期望结果：原图均值 51.0 与 22.95；裁剪区域二值化后的均值 95.625 与 191.25，二者不同，说明均值取的是裁剪前的原图。
- 输入资源：`images/`，随软件提供。
