# 逻辑表达式与条件分支

- 前置条件：与 Python图像统计相同，需要在 设置 → Python 环境 选定可用解释器；本工程的两个逻辑节点也由 Python 工具实现。
- 使用：文件 → 打开示例… → 本目录的 `逻辑表达式与条件分支.vrt.json`。
- 流程：图像读取 → 计算图像均值 → 评估表达式 → 条件分支。
- 表达式：`is_bright = mean[0] > 50.0`、`deviation = abs(mean[0] - 50.0)`；条件分支的条件来源为上层布尔，直接读取 `is_bright`。
- 期望结果：第 1 张均值 51.0，判定成立，偏差 1.0；第 2 张均值 22.95，判定不成立。分支状态端口分别给出 0 与 1。
- 试一试：把表达式的 50.0 改成 30.0，再运行一次，两张图的判定与分支状态都会翻转。
- 输入资源：`images/`，随软件提供。
