# 变距尺子标定测量

打开 [工程](变距尺子标定测量.json)，在设置中选择含 NumPy 的 Python 环境，然后执行流程。原图位于 [集中图片目录](../../images/变距尺子标定测量/)。

平面标定的训练页保存标定板原图和 [描述文件](calplate_80mm.cpd)，可在现有训练视图重新应用标定。检测图中的参考线长度为 55 mm，用于确定当前测量平面的尺度。中心距统计输出平均值（mm）和样本标准差（μm）。

模型归工程旁的资产目录；训练样本随工程参数保存。算法与实际数值验证见 [工具验证](../../../tests/calibration_example_contract.cpp)。
