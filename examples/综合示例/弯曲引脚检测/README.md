# 弯曲引脚检测

打开 [工程](弯曲引脚检测.vrtapp)，在设置中选择含 NumPy 的 Python 环境，然后单步或连续执行流程遍历全部 9 张连接器图像。原图位于 [集中图片目录](../../images/弯曲引脚检测/)。

对齐模型与参考图打包于 `assets/alignment-model.zip`，存在性检测的单引脚模板、25 个参考位点与训练原图打包于 `assets/presence-model.zip`。可在训练视图中直接查看或重新应用“对象模板样本”与“参考位置样本”两个数据集。

所有相对路径基于安装目录解析；逐帧良/不良判定与训练重发验证见 [示例验证](../../../tests/merlic_examples_contract.cpp)。
